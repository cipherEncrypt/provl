# Provl brand marks

Grayscale logo system for Provl (proof / verified verdict).

## Recommended

**Concept A**: geometric **P** with a **proof check** crossing the bowl.

| Asset | Light background | Dark background |
| --- | --- | --- |
| Mark (32×32) | `provl-mark-a-dark.svg` | `provl-mark-a-light.svg` |
| Wordmark | `provl-wordmark-a-dark.svg` | `provl-wordmark-a-light.svg` |

In the app, use `<ProvlLogo />` and `<ProvlMark />` from `components/ProvlLogo.tsx` (Geist wordmark).

## Alternates

- **B**: verdict seal (circle + check): `provl-mark-b-*.svg`, `provl-wordmark-b-dark.svg`
- **C**: proof bracket (frame + check): `provl-mark-c-*.svg`, `provl-wordmark-c-dark.svg`
